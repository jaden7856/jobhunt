# 공고 현황표 (posting report)

Scope: the weekly posting report generated by `scripts/report_html.py` into `data/search/reports/postings.html` — one self-contained static HTML file (no external CSS/JS; only the title face loads from Google Fonts, with installed Myeongjo fallbacks), openable by any browser and any AI agent. Mode: Operate.

Audience/job: one Korean backend developer on a Mac browser, weekly after a scan, picking what to apply to and checking application states and deadlines; occasionally shown to a mentor who has never seen the tool.
Content: 100–200 open postings (회사, 포지션, 근무지, 점수 1–5, 판정, 새로 찾음, 마감, 한 줄 근거, 원문 링크, 항목별 점수), plus application records (지원함·불합격 …).
Constraints: Korean UI text; no personal data in repo; the file must work without any host feature; Artifact publishing is optional delivery.
Memorable moment: each 지원 권장 row carries a red seal stamp in a fixed cell, and a row unfolds its itemised score like a form's 비고 attachment.
Unresolved: filtering depth beyond inline script (kept to verdict-band jump + text search).

## Direction contract

THESIS: The queue is issued as one official certificate — a ruled 공문 서식 with 발급 번호, 결재란 and 판정 도장 — refusing the SaaS card-and-pill dashboard.

OWN-WORLD: White form paper, 0.5px black rules, pale steel-grey header cells (#e3e7ec), seal-red 인주 (#b3122e) only for 지원 권장, ink-blue (#1f3a8a) for 지원 고려 and links, grey for 보류, struck-through grey for 불합격. Title and band heads in Myeongjo (Nanum Myeongjo 800, fallback AppleMyungjo/Batang) like a certificate heading; body and numerals in the system Korean gothic (Apple SD Gothic Neo / Malgun Gothic) with tabular numerals in fixed-width cells. Dark mode = carbon copy: charcoal paper, light rules, same seal logic.

STORY: The visitor sees how many postings are worth applying to, jumps to that band, compares score and reason row by row, opens the original posting, and notices anything closing within a week.

FIRST VIEWPORT: Top band = title "공고 현황" left, 발급일·발급 번호 right, a 결재란-style box of counts per verdict (each a link to its band). Below, the 지원 권장 band opens immediately: ruled table, score cell with seal, 마감 cell flagged when ≤7 days.

FORM: 공문 서식표, candidate 6 of 7 on the ordered list; seed key e77f017d. Raises: fixed-width cells (Crouwel grid), colour-as-law (CRT), leader-line itemised score (tensegrity), bands darkening top-to-bottom (cyclorama).
