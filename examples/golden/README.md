# 판정 정답 세트

공고 줄 분류 규칙(`references/scoring.md`)을 바꿨을 때, 에이전트의 판정이 정답에서 얼마나 벗어나는지 재는 가상 사례 모음입니다.

| 파일 | 내용 |
|---|---|
| `candidate.md` | 가상 지원자의 경력·조건·선호 (판정의 유일한 근거) |
| `scoring.yaml` | 가상 지원자의 개인 선호 (`score.py` 계산용) |
| `postings/` | 가상 공고 본문. 파일마다 규칙 하나의 경계 사례 |
| `answers/` | 정답 판정. `rule:` 이 무엇을 확인하는지, `expect:` 가 기대 결론 |

실행 절차는 `references/scoring.md` "Golden set". 요약하면 에이전트가 `answers/` 를 보지 않고 공고를 분류해 다른 폴더에 저장하고,
`python3 scripts/eval_golden.py <그 폴더>` 로 줄 단위·결론 일치율과 어긋난 줄을 봅니다.

| 사례 | 확인하는 규칙 |
|---|---|
| 01 | 필수의 다른 언어 + "또는 이에 준하는 역량" → 스택 조건 통과, 그 줄은 미충족(bridge) |
| 02 | "언어 무관" 필수는 충족, 자격요건 밖 기술 스택 절은 팀 스택 |
| 03 | 우대에 있어도 포지션 핵심 기술은 key — 못 채우면 C |
| 04 | 처음인 전문 기술 도메인(LLM 서빙) → domain_new, 주요 업무 절반 이상 new |
| 05 | 필수 경력·도메인이 없으면 core, 대체 문구가 있으면 alt |
| 06 | 대체 문구 없는 core 빈틈 |
| 07 | 태도·성향 줄은 필수에서 뺀다 |
| 08 | 필수를 다 채워도 주요 업무 절반 이상이 new 면 C |
| 09 | 주 업무가 피하는 일이면 개인 상한 |
| 10 | 근무지 조건 밖 → 점수 없이 제외 |
