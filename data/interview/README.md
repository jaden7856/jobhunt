# interview/

면접 준비 자료 (modes/interview.md).

- `<회사>_<포지션>.md`: 지원 건마다 만드는 연습지 — 전형별 준비, 이력서에서 나올 질문과 꼬리질문, 기술 질문, 행동 질문, 역질문
- `stories.md`: 행동·협업 질문에 쓸 실제 사례 모음 (장애, 일정, 처음 맡은 기술, 갈등, 되돌린 결정, 이직 사유). 한 번 정리해 회사마다 재사용
- `log.md`: 면접 후 기록 — 받은 질문, 막힌 답, 결과

공부 노트가 따로 있으면 위치를 `data/preferences/standing.md` 의 "면접 공부 노트"에 적는다.
